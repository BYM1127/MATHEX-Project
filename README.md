# MATHEX-Project // High-Spec Engineering & Architecture

Created by **Bokamoso Sebake**.

Specializing in monolithic civil infrastructure, brutalist residential architecture, and specialised geotechnical foundations across sub-Saharan Africa.

## Tech Stack
- **Frontend**: React (Next.js 14 App Router, TypeScript)
- **Styling**: Tailwind CSS
- **Design System**: Dark theme technical brutalism, JetBrains Mono, Space Grotesk, Hanken Grotesk
- **Backend**: Next.js Serverless API routes (Vercel-ready)

## Pages
1. **Home** (`/`): Flagship Steyn City Residence & Commercial Towers, quantitative field metrics, selected structural works, CAD & heavy tectonics.
2. **Portfolio** (`/portfolio`): 6 detailed dossiers, dynamic category filter, 28-commission Technical Archive Registry with CSV export.
3. **Philosophy** (`/philosophy`): Geological Imperative, 4 Tectonic Pillars, Finite Element Stress Analysis vs. Realised Form SVG viewer, Craftsmanship monograph.
4. **Services** (`/services`): Core operational scopes, interactive Scope & Quantity Estimator calculator, 4-Stage Execution Protocol.
5. **About Us** (`/about-us`): Executive leadership, statutory accreditations registry, 18,000m² Main Reef Depot logistics & fleet readiness index.
6. **Contact** (`/contact`): Form 04-A specification entry, dispatch radar, project audit cards, interactive FAQ accordions.
7. **Policy** (`/policy`): Interactive 5-tab statutory compliance hub, 2025 compliance audit schedule table, downloadable certificate repository.

## Running Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

Configured for immediate deployment on Vercel. Simply import this repository into your Vercel account.
